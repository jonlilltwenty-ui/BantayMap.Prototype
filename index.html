Bantay Map Prototype — System Guide

          
Operational Reference for Project BantayRiles Dashboard

        

        
      

      

        

          
1. Map Symbols & Operational Statuses

          
    
            
  • CLEAR (Green): Track is clear; dual 3.5m fiberglass drop arms are upright.
    • 
            
  • PRE_ALERT (Amber): 2-of-3 sensors confirmed an approaching train; ≤3 Hz LED strobes and 90 dB chimes activate 5–7s before gate descent.
    • 
            
  • GATE_LOWERED (Red): Entrance drop arm lowers first, followed 3s later by exit arm (25s before train arrival).
    • 
            
  • POST_PASS_HOLD (Blue): Safety buffer keeping gates closed for 5.0 full seconds after the train clears the crossing before reopening.
    • 
            
  • FAULT (Purple): Hardware tamper switch, low battery, or gate overcurrent obstruction alert.
    • 
          

        

        

          
2. Map Controls & Simulation Buttons

          
    
            
  • Simulate Corridor Run (Spot 1 → Spot 2): Spawns an animated PNR locomotive along the georeferenced Laguna–Quezon railway line, testing Spot 1 and Spot 2 sequentially with the 5.0-second post-pass hold.
    • 
            
  • Map Zoom & Pan Controls (+, −, 100%): Zoom into the San Pablo Pilot Sector up to 260% using buttons or mouse scroll wheel, and drag the map background to pan.
    • 
            
  • Hotspots (ON/OFF): Toggles crimson (pambabato stone-throwing) and amber (track debris) heat zones submitted via QR codes.
    • 
            
  • Align Pins (ON/OFF): Unlocks Spot 1 and Spot 2 pins so you can drag them along the track line.
    • 
            
  • Developer Menu: Opens state checkpoint snapshots, Rollback restore, and Custom Map Image upload tools.
    • 
          

        

        

          
3. Dashboard Workflow & Compliance

          
    
            
  • 2-of-3 Sensor Fusion: Requires agreement between at least 2 sensors (AI Vision, Piezo Vibration, or 24GHz Doppler Radar) to eliminate false triggers from parallel road traffic.
    • 
            
  • Riles Marshal Dispatch: Tracks the 2-minute (120s) target window for barangay marshals to secure crossings after automated SMS dispatch.
    • 
            
  • RA 10173 & RA 9710 Compliance: QR incident logs store anonymized coordinates and hazard notes without personal commuter surveillance.
    •

      const dy = points[i + 1].y - points[i].y;

      total += len;
    }
